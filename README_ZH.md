## 基于 NestJS 的项目

### 开源项目

- Ever®：面向按需经济与数字市场的开源电商平台。
- Gauzy：面向现代创意机构与工作室的开源利润分账平台。
- Novu：具备嵌入式通知中心的开源通知基础设施。
- Pimp My PR：用于统计与拉取请求管理的开源平台。
- Teable：一款快速、实时、面向开发者的无代码数据库。
- ToolJet：低代码内部工具平台。
- Vendure：基于 NestJS 的无头 GraphQL 电商框架。
- Amplication：用于自动生成 TypeScript 与 Node.js 后端应用的开源低代码工具。
- Undb：基于 SvelteKit 与 SQLite 的无代码数据库。
- Manifest：面向 AI 代理的实时成本可观测平台。
- IdeaForge：结合协作编辑与 AI 能力的文档协作平台。
- Bunnychess：基于 NestJS 微服务与 NATS JetStream 的可扩展棋类服务。
- Hoppscotch：使用 NestJS 后端的开源 API 开发生态。
- Enclave：自托管的 AI 社交世界，后端基于 NestJS + TypeORM + SQLite。
